# Как спрайтеру отправить работу в сборку

Гайд для тех, кто рисует, но ещё не работал с GitHub. Кодить не нужно.

## Коротко

Спрайт в Space Station 14 — это не одна картинка, а **папка** с расширением `.rsi`
(Robust Station Image). Внутри лежат PNG-кадры и файл `meta.json`, который описывает,
что это за спрайт, какого он размера и **под какой лицензией**.

```
Bonfire.rsi/
  meta.json
  bonfire.png
  bonfire-on.png
```

Без `meta.json` сборка спрайт не увидит. Без правильной лицензии в нём — у проекта
будут проблемы, когда сборку кто-нибудь форкнет.

## Заполнение meta.json

```json
{
    "version": 1,
    "license": "CC-BY-SA-4.0",
    "copyright": "By Wandom (Discord/Github)",
    "size": { "x": 32, "y": 32 },
    "states": [
        { "name": "bonfire" },
        { "name": "bonfire-on", "delays": [[0.2, 0.2, 0.2]] }
    ]
}
```

Поля `license` и `copyright` — обязательные. Правила такие:

| Откуда спрайт | license | copyright |
|---|---|---|
| Нарисован вами с нуля | `CC-BY-SA-4.0` | `By ВашНик (Discord/Github)` |
| Взят с /tg/station и перерисован | `CC-BY-SA-3.0` | `Taken from tgstation at commit <хеш> and resprited by ВашНик` |
| Взят с офов или CrystallPunk | та же, что в исходном meta.json | `Taken from <проект> and resprited by ВашНик` |

**Важно:** нельзя писать «использование в других проектах запрещено». Workshop проекта
работает по CC-BY-SA, а она по своей сути разрешает использование кому угодно при условии
указания авторства. Эти два требования противоречат друг другу, и запрет в такой ситуации
юридически не работает — зато ломает совместимость с апстримом.
Ваше авторство защищает именно поле `copyright`: его обязаны сохранить все, кто возьмёт спрайт.

## Куда класть файлы

Всё наше — только в папки `_Frosthold`, чужие не трогаем:

```
Resources/Textures/_Frosthold/<категория>/<Название>.rsi/
```

Например: `Resources/Textures/_Frosthold/Structures/Bonfire.rsi/`

## Как отправить: через сайт, без установки программ

Самый простой путь, если вы на GitHub первый день.

1. Зайдите на https://github.com/egorchaev/Frosthold
2. Нажмите **Fork** (правый верхний угол) — появится ваша личная копия репозитория
3. В своей копии откройте папку `Resources/Textures/_Frosthold/`
4. **Add file** → **Upload files**, перетащите папку `.rsi` целиком
5. Внизу в поле описания напишите, что добавили: например `sprites: респрайт костра`
6. Выберите **Create a new branch** и нажмите **Propose changes**
7. На следующем экране нажмите **Create pull request**

Готово. Pull request («запрос на слияние») — это предложение добавить ваши файлы
в основную сборку. Егор его посмотрит и примет.

Если что-то пошло не так — ничего не сломается. Пул-реквест можно закрыть и сделать
заново, на основную сборку это никак не влияет.

## Что ещё нужно, кроме спрайта

Чтобы предмет появился в игре, нужен ещё **прототип** — описание в YAML, которое говорит,
что это за объект и какой спрайт использует. Его пишет разработчик или прототипер.
Спрайтеру достаточно прислать `.rsi` — остальное подключат.

Если хотите сделать и прототип сами, смотрите соседний файл `FROSTHOLD.md`.
